SwadeshiYatra: In-Depth Project Guide, Tech Stack, & Resume Roadmap

SwadeshiYatra is an AI-powered travel planner web application built specifically for exploring destinations across India. It supports single-city deep-dives (City Planner) and multi-city sequential itineraries (Journey Planner), along with local service provider integration (guides, hotels, restaurants).

========================================================================
1. The Core Tech Stack
========================================================================

If you list this project on your resume, describe the tech stack using these professional industry terms:

* Frontend Framework: Next.js 16 (React 19, TypeScript) utilizing the modern App Router for layout-based routing and hybrid client/server rendering.
* Styling & UI: Tailwind CSS (PostCSS) for highly responsive, grid/flex-based, utility-first components with clean micro-animations.
* Database & Storage: SQLite (via sqlite & sqlite3 packages) storing relational user accounts, session tokens, and verified service providers locally.
* AI & Large Language Models (LLM): Google Gemini API (@google/generative-ai) leveraging the Gemini 2.5 Flash model for sub-second, structured JSON completions.
* External APIs: Wikipedia/Wikimedia API for dynamic, contextual place image matching based on articles.
* Auth & Security: Custom cookie-based session management using Node's standard crypto module (scryptSync for salted password hashing, timingSafeEqual to prevent timing side-channel attacks).

3. Software Design & Key Architectural Patterns
========================================================================

To stand out in technical interviews, you should explain the following architectural design choices:

A. The Robust JSON Extractor & Sanitizer
LLMs are naturally conversational and prone to outputting markdown wrappers (e.g. ```json) or extraneous text. 
* How it works: Located in lib/gemini.ts, extractJsonBlock runs a balanced-bracket parsing algorithm to find the exact starting [ or { and matches it with its closing ] or }.
* Benefit: This guarantees that formatting abnormalities generated by the AI are discarded, preventing runtime parsing exceptions (JSON.parse failures).

B. Custom Disk-Persistent Caching
API queries to LLMs can be slow (taking 3-15 seconds) and run up API usage costs quickly.
* How it works: Implemented in lib/cache.ts, the PersistentCache class serializes active cache queries to .gemini-cache.json on disk. 
* Benefit: Even when the local server restarts or undergoes Hot Module Reloading (HMR) during development, cached travel data persists. This results in 0ms response times for repeated queries and bypasses rate limits entirely.

C. Sequential Route Alignment Prompting
Standard AI-generated routes can back-track (e.g., traveling from Mumbai to Pune, then back to Mumbai, then to Delhi).
* How it works: Prompt templates explicitly enforce the model to sequence cities strictly linearly based on geographical alignment, calculate the absolute nearest passenger airport to the entry city, and format responses with type-safe metadata.

D. Zero-Dependency Secure Session Authentication
Instead of introducing heavy libraries like NextAuth, the project utilizes a lightweight, built-in cryptographically secure setup:
* Uses cryptographically random UUIDs as session tokens.
* Authenticates queries via HttpOnly, Secure, SameSite=Lax cookies, securing them from Cross-Site Scripting (XSS) attacks.
* Performs secure password storage using scryptSync with unique random salts.

5. Deep-Dive Skills to Master for Interviews
========================================================================

If a hiring manager asks you questions about this project, make sure you can answer the following:

1. Next.js Server & Client Components: Understand when to use 'use client' (for interactivity, useState, useEffect) vs Server Actions/Route Handlers (for secure database operations, reading file systems, and API key management).
2. HTTP-Only Cookies vs LocalStorage: Explain that tokens are stored in HttpOnly cookies to protect against XSS (Cross-Site Scripting), whereas LocalStorage is accessible by JavaScript scripts and therefore insecure for authentication tokens.
3. JSON Schema Enforcement (Gemini API): Explain how you configured responseMimeType: "application/json" in the getGenerativeModel config to instruct Gemini to return parsed code instead of general chat, combined with prompt schema rules.
4. Database Indexing & Queries: Be ready to explain the users and sessions database schema in SQLite. Explain how token is set as the primary key in sessions to ensure O(1) fast lookups during user validation requests.
5. Rate Limits and Rotating Keys: Explain how the project split API key strings and can rotate them to avoid hitting API rate limits during heavy usage.
